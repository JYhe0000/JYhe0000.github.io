关于smartisanR1的改装设想

# 1. 目标

将坚果 R1 改造成一台以 USB-C DisplayPort
输出为主、具备手机内屏辅助交互能力的 Android TV 设备。

通俗地，坚果r1将采用类似车机的方式，Touch Bar的定位，将手机屏幕用作副屏，而输出的信号与屏幕显示的信号不同。

产品不是简单更换手机桌面，而是一个经过设备配置、显示策略、系统应用和交互层定制的电视系统。

# 1.1 核心思路

  • 电视通过 USB-C DP 转 HDMI 连接，作为主要观看屏幕。
  • HDMI 显示专用 TV Launcher 和电视应用。
  • R1 自带 LCD 屏幕保留为辅助 Hub。
  • Hub 平时显示时间、日期、连接状态和播放等等信息。
  • Hub 可临时切换到虚拟触控板或遥控器，控制电视端光标。
  • 两块屏幕独立显示，不做简单镜像。
  • 电视端播放、内屏控制和系统后台服务应互不干扰。

# 2. Android 基线选择

# 2.1 采用设备旧版 LineageOS 分支

截至文档日期，LineageOS 主线已出现更新的大版本，但 Smartisan R1
官方设备树仍处于 lineage-22.2 分支。R1 的官方设备资料列出 LineageOS
22.2（Android 15），而本项目采用Android 10分支

项目 决定

ROM 基础 LineageOS 22.2
Android 版本 Android 10
设备代号 trident
产品型号 DE106
SoC Snapdragon 845 / SDM845
GPU Adreno 630
内核基线 R1 设备树所匹配的 Qualcomm kernel
产品目标 自定义 R1 TV OS

重要： "最新 Android"不等于"该设备可用的最新 ROM"。不应把 LineageOS
24.0 / Android 17 的通用源码直接当作 R1 已支持的构建基线。若未来 R1
官方设备树升级分支，应先评估设备树、内核、Vendor blobs、固件和 DP
显示链路，再决定是否迁移。

# 3.功能定义

# 3.1 HDMI 主屏

HDMI 是主要观看和应用交互屏幕，目标功能：

  • TV Launcher 首页。
  • D-pad / 遥控器焦点导航。
  • Kodi、YouTube、Netflix 等电视应用入口。
  • 系统设置、网络、蓝牙、音量和显示设置。
  • 媒体播放时保持 TV 端应用在前台。
  • HDMI 热插拔后能恢复显示。
  • HDMI 音频可用。

电视端 UI 应使用 10-foot UI
设计原则：远距离可读、大焦点、清晰层级、遥控器优先，避免照搬手机布局。

# 3.2 R1 内屏 Hub

内屏是辅助控制屏，不作为日常 Android 手机桌面。

# 状态 A：Ambient Hub

默认常驻界面： - 大号时间。 - 日期、星期。 - Wi-Fi / 蓝牙状态。 - DP /
HDMI 连接状态。 - 当前播放状态。 -
设备温度或运行状态（可选，需控制刷新频率）。

# 状态 B：Virtual Touchpad

建议手势： - 单指移动：移动 HDMI 屏幕光标。 - 单指轻点：左键。 -
双指移动：滚动。 - 长按并移动：拖拽。 - 双指轻点：可选右键。 -
触控板界面提供退出按钮，避免用户无法返回 Hub。

手势必须允许用户自定义；不应将复杂手势作为唯一操作方式。
